# Ribbon

Ribbon is a performance optimization mod for Minecraft 1.20.1 Forge, forked from Embeddium 0.5.8. It is specifically designed to provide a stable, high-performance rendering pipeline while maintaining full compatibility with Oculus and PBR.

## Features

- Fully compatible with Oculus 1.7.0 and PBR resource packs.
- Custom FPS/TPS overlay, configurable via the video settings.
- Customizable block outline with multiple color modes.
- Chunk rendering and loading statistics.
- Sodium-level rendering optimization for the Forge platform.

## Requirements

- Minecraft 1.20.1
- Forge 47.x
- Java 17

Note: This mod is a standalone fork. You do not need to install the original Embeddium mod alongside Ribbon.

## Installation

1. Install Minecraft Forge for 1.20.1.
2. Download the latest `ribbon-*.jar` from the Releases page.
3. Place the jar file into your `.minecraft/mods` folder.
4. Optional: Install Oculus and a compatible shader pack for the complete experience.

## Known Issues

- Minor visual artifacts (flickering) may occur when using specific shader packs, such as Revelation. Using RTITRP or BSL shaders is recommended for the best visual stability.

## 中文说明

Ribbon 是一款基于 Embeddium 0.5.8 分支开发的 Minecraft 1.20.1 Forge 性能优化模组。它旨在提供稳定、高效的游戏渲染体验，并完美兼容 Oculus 光影与 PBR 材质。

### 功能特性

- 完美兼容 Oculus 1.7.0 与 PBR。
- 自定义 FPS/TPS 悬浮窗（可在视频设置中开关）。
- 方块彩虹描边（支持多种颜色模式）。
- 区块加载与渲染监控数据。
- 在 Forge 平台上提供 Sodium 级别的渲染优化。

### 环境要求

- Minecraft 1.20.1
- Forge 47.x
- Java 17

注：本模组为独立分支版本，无需额外安装原版 Embeddium。

### 安装方法

1. 安装对应 1.20.1 版本的 Minecraft Forge。
2. 从 Releases 页面下载最新的 `ribbon-*.jar`。
3. 将 JAR 文件放入 `.minecraft/mods` 文件夹中。
4. 可选：安装 Oculus 及兼容的光影包以获得完整视觉体验。

### 已知问题

- 使用特定光影包（如 Revelation）时，画面边缘可能会出现轻微闪烁。建议使用 PHOTON 或 BSL 光影以获得最佳稳定性。
